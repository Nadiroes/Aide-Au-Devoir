     1→# Worklog — Aide au Devoir ( Homework Help App )
     2→
     3→Project: Next.js 16 + TypeScript + Tailwind 4 + shadcn/ui + Prisma/SQLite.
     4→Goal (from user's pasted spec): French homework-help app.
     5→- Import courses (PDF, DOCX, TXT, PNG, JPEG) with title + subject.
     6→- Ingestion agents scan documents and announce when ready (real-time SSE).
     7→- Multi-agent chat pipeline: Planificateur → Chercheur (RAG) → Solveur → Tuteur, streamed agent-by-agent.
     8→- API key management for Mistral + Agnes (test / save encrypted / delete / status) + built-in Z.ai provider so the app works without keys.
     9→- Single visible route `/` (tab navigation: Accueil, Cours, Assistant, Paramètres).
    10→
    11→Key decisions (Task 1):
    12→- Everything in Next.js (no separate Python backend). Node ports of ingestion + retrieval + LLM router.
    13→- PDF text: `unpdf`; DOCX: `mammoth`; TXT/MD: direct read; PNG/JPEG: z-ai VLM (base64 data URL) with tesseract CLI fallback.
    14→- Vector store replaced by BM25 lexical search over Chunks in SQLite (French-aware normalization: accent-strip, stopwords, plural-stem) — robust, zero external services.
    15→- API keys encrypted with AES-256-GCM (`src/lib/secretbox.ts`), master key from env MASTER_KEY or auto-generated `db/master.key`. Never returned raw — masked only.
    16→- LLM providers: `zai` (built-in SDK, default, no key), `mistral` (api.mistral.ai, streaming SSE), `agnes` (OpenAI-compatible adapter configured via AGNES_BASE_URL/AGNES_MODEL/AGNES_TEST_PATH/AGNES_AUTH_STYLE env vars).
    17→- SSE contract defined in `src/lib/types.ts` (shared client/server types).
